# HackSort AI Insight

Build a complete working web app called "HackSort AI" from scratch.

HackSort AI is an AI-powered hackathon judging intelligence platform that helps judges review large numbers of submissions, discover similar ideas, identify overlooked innovative projects, and make better final decisions.

IMPORTANT: Build the complete functional prototype in one generation. Use realistic mock/demo data and working interactions. Do not leave major buttons as placeholders.

10. ⭐ HIDDEN GEMS

==================================================

This is the main USP.

Create a "Potential Hidden Gems" section.

Identify projects that have:

HIGH:

- Innovation

- Impact

- Technical potential

but LOW:

- Presentation quality

Example:

AgriRecover

Innovation: 91

Impact: 90

Technical: 81

Presentation: 48

Label:

"Potential Hidden Gem"

Show an AI explanation such as:

"Strong innovation and real-world impact detected despite comparatively weak presentation quality. Recommended for judge review."

Important:

AI must NOT declare the winner.

It only recommends projects for a second look.

Show:

"AI recommendation — final decision remains with the judge."
